# בוט חיפוש טיסות לוואטסאפ

מחבר בין קבוצת וואטסאפ לבין ה-endpoint `POST /api/flights/search-bot` באתר.
כותבים "טיסה" בקבוצה, הבוט שואל מאיפה, לאן ובאילו תאריכים, ומחזיר קישורים
אמיתיים ל-Google Flights ול-Skyscanner.

## ⚠️ חשוב לדעת לפני שמריצים

- **וואטסאפ אין לו Bot API רשמי לקבוצות.** הסקריפט הזה מדמה חיבור של
  מכשיר נוסף (Linked Device) דרך [Baileys](https://github.com/WhiskeySockets/Baileys) —
  ספרייה חופשית בקוד פתוח, אבל לא רשמית. זה חייב תהליך שרץ **24/7** —
  לא ניתן להריץ את זה בתוך Claude Code או ב-Vercel (serverless).
- זה מנוגד לתנאי השימוש של וואטסאפ ויש סיכון (נמוך אך קיים) לחסימת המספר.
  מומלץ להשתמש במספר טלפון ייעודי לבוט, לא במספר האישי שלכם.
- הקוד הזה **לא נבדק בפועל מול שרת וואטסאפ אמיתי** (אין גישה לרשת כזו
  בסביבת הפיתוח שבה זה נכתב) — יכול להיות שיידרשו התאמות קטנות.

## הרצה

1. `cd scripts/whatsapp-flights-bot && npm install`
2. `cp .env.example .env` ומלאו:
   - `WEBHOOK_URL` — הכתובת המלאה של `/api/flights/search-bot` באתר החי שלכם
   - `FLIGHTS_BOT_SECRET` — מחרוזת סודית ארוכה, **אותו ערך בדיוק** צריך
     להיות מוגדר גם כמשתנה סביבה `FLIGHTS_BOT_SECRET` בפרויקט ב-Vercel
3. `npm start`
4. במסוף יופיע קוד QR — סרקו אותו מהטלפון: וואטסאפ ← הגדרות ← מכשירים
   מקושרים ← קישור מכשיר. פרטי ההתחברות נשמרים בתיקיית `auth/` כך שלא
   תצטרכו לסרוק שוב בכל הפעלה.
5. פתחו/צרו את קבוצת הוואטסאפ ושלחו בה כל הודעה. המסוף ידפיס את ה-JID של
   הקבוצה (`123...@g.us`) — העתיקו אותו לתוך `.env` בתור `GROUP_JID` כדי
   שהבוט יגיב רק בקבוצה הזו (בלי זה הוא יגיב בכל צ'אט שיפנה אליו).
6. הפעילו מחדש עם `npm start`.

## שימוש בקבוצה

- כותבים "**טיסה**" (או כל משפט שמכיל את המילה) כדי להתחיל חיפוש.
- הבוט שואל: מאיפה? → לאן? → תאריך יציאה? → תאריך חזרה (או "הלוך" לכרטיס
  חד-כיווני).
- מחזיר קישורים ל-Google Flights ו-Skyscanner (Skyscanner רק לערים
  שמוכרות ל-`lib/flights-search/constants.ts` — אפשר להוסיף עוד ערים שם).
- אפשר לבטל חיפוש באמצע עם "ביטול".

## הרצה קבועה (24/7)

הרצה מקומית תיפסק כשהמחשב נכבה. אפשרויות להשארה פעילה:

- **PM2** על שרת/VPS קטן קיים: `npx pm2 start index.js --name flights-bot`
- שירות חינמי/זול עם תהליך מתמשך (לא סביבת serverless) — Railway, Render
  (Background Worker), fly.io וכו'. התחברו פעם אחת מקומית (סריקת QR),
  ואז העתיקו את תיקיית `auth/` לשרת כדי שלא יידרש סריקה מחדש.
- `systemd` service אם יש לכם שרת לינוקס משלכם.
