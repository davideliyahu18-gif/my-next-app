# בוט כדורגל — כל הליגות (WhatsApp)

בוט WhatsApp (Baileys) שמביא התראות כדורגל ממקור **FIFA** ושולח לקבוצה.

## מה הוא עושה

- התראות אוטומטיות: **שער · פתיחה · מחצית · סיום · תזכורת 30 דק׳**
- שלט רחוק בקבוצה: `תוצאה` · `מחר` · `לוח` · `ליגות` · `עזרה`
- קישור במכשיר מקושר עם **סריקת ברקוד (QR)**

## 1) הגדרה ב־`.env.local`

```bash
FOOTBALL_BOT_SITE_URL=http://127.0.0.1:3000
FOOTBALL_BOT_SECRET=generate-a-long-random-secret
FEED_API_SECRET=generate-a-long-random-secret

# שם הקבוצה (חלקי מספיק) — או chat id מלא אחרי החיבור
FOOTBALL_WHATSAPP_GROUP_NAME=דוד | עדכוני כדורגל
# FOOTBALL_WHATSAPP_CHAT_ID=120363...@g.us

# אופציונלי — מקור FIFA שתביא:
# FOOTBALL_FIFA_BASE_URL=https://api.fifa.com/api/v3
# FOOTBALL_FIFA_COMPETITIONS=17,10005,158
# או JSON:
# FOOTBALL_FIFA_COMPETITIONS=[{"id":"17","nameHe":"גביע העולם","seasonId":"285023"}]
```

## 2) הפעלה + סריקת ברקוד

טרמינל 1 — אתר:

```bash
npm run dev
```

טרמינל 2 — בוט:

```bash
npm run football-bot:setup
npm run football-bot:start
```

יופיע QR בטרמינל + קובץ:

`scripts/football-whatsapp/qr.png`

בטלפון: **WhatsApp → הגדרות → מכשירים מקושרים → קישור מכשיר → סרוק**.

## 3) שליחה לקבוצה

1. צרו / היכנסו לקבוצה (למשל `דוד | עדכוני כדורגל`)
2. הוסיפו את **המספר המקושר** לקבוצה
3. הבוט שולח הודעת «בוט כדורגל מחובר»
4. כתבו בקבוצה `עזרה` או `תוצאה`

|--------|---------|

| `לוח 1` / `לוח אנגלית` | לוח פרמייר ליג |
| `לוח 2` / `לוח ספרדית` | לוח לה ליגה |
| `לוח 3` / `לוח ישראלית` | לוח ליגת העל |
| `לוח 4` / `לוח איטלקית` | לוח סרייה א׳ |
| `לוח 5` / `לוח גרמנית` | לוח בונדסליגה |
| `לוח 0` / `לוח הכל` | כל הליגות |
| `טבלה` | תפריט — בחירת ליגה לדירוג עדכני |
| `טבלה 1` / `טבלה אנגלית` | טבלת פרמייר ליג **כתמונה** |
| `סגל` / `סגל ברצלונה` | סגל שחקנים עדכני **כתמונה** (ברירת מחדל: ברצלונה במעקב) |
| `שחקנים` / `רשימת שחקני ברצלונה` | אותו דבר כמו `סגל` |
| `הרכב` | תפריט כפתורים — בחירת ליגה להרכב |
| `הרכב 1` / `הרכב אנגלית` | הרכב למשחק הבא בליגה |
| `עקוב ברצלונה` | הוספת קבוצה למעקב |
| `מעקב` | רשימת קבוצות במעקב |
| `הסר ברצלונה` | הסרת קבוצה מהמעקב |
| `בוקר` | בדיקת תקינות מעוצבת לליגות (גם אוטומטי ב־08:00 ישראל) |
| `תוצאה` | משחקים חיים / קרובים |
| `מחר` | משחקי מחר |
| `ליגות` | רשימת ליגות במעקב |
| `בדיקה` / `חי` / `פינג` | בדיקה מהירה שהבוט חי (**מומלץ** במקום סטטוס) |
| `סטטוס` / `בוט` | האם הבוט מחובר |
| `עזרה` | רשימת פקודות |

אחרי `לוח` / `הרכב` נפתחת **רשימת כפתורים** לבחירת ליגה (WhatsApp native flow).  
אפשר גם לענות במספר / שם: `1` / `אנגלית` / `ספרדית`.

**חשוב:** אל תפתחו סשן Baileys שני — זה מפיל את הבוט (קוד 428).  
`announce-*` / `send-group` שולחים רק דרך outbox. נעילת `bot.lock` מונעת סשן כפול.

**התאוששות אוטומטית (בלי לבקש ממני להפעיל):**
- נפילה → reconnect חכם (ב־428 ממתין ~12–45ש עד שהסשן הישן מת)
- Keep-alive כל 3 דק׳; reconnect רק אחרי 3 כשלונות רצופים
- Supervisor לא הורג על קפיצת שעון/שינה של הסביבה בטעות; SIGKILL רק לאותו תהליך תקוע (לא לילד החדש)
- `npm run football-bot:ensure` — מפעיל רק אם באמת נפל (לא הורג חיבור חי / לא בזמן reconnect)
- הודעות «חזרתי» לקבוצה כבויות כברירת מחדל (`FOOTBALL_BOT_NOTIFY_RECOVER=true` להפעלה)

**למה נופל (קוד 428):** כמעט תמיד «החיבור הוחלף» — סשן שני על אותו מספר (ריסטארט אגרסיבי / סקריפט announce / מכשיר מקושר נוסף). לא טיימר של כל שנייה.

**בדיקה שעתית גלויה:** כל שעה עגולה (שעון ישראל) הבוט שולח לקבוצה הודעת «בדיקת תקינות שעתית» עם ✅.  
`בדיקה` / `חי` / `סטטוס` נענים מקומית (בלי API) ולא מפילים את החיבור.

תזכורות אוטומטיות: **60 דק׳** ו־**30 דק׳** לפני משחק (כולל הרכב כשפורסם).

סטטוס בוקר אוטומטי: כל יום **08:00** (שעון ישראל) — הבוט שולח שהוא חי ומחכה למשחקים שמתחילים בקרוב ⚽️🔥  
(`FOOTBALL_BOT_MORNING_CRON=0 8 * * *`, `FOOTBALL_BOT_MORNING_TZ=Asia/Jerusalem`)

כפתורי ליגה: `FOOTBALL_BOT_BUTTONS=true` (ברירת מחדל). הגדירו `false` כדי לחזור לתפריט טקסט בלבד.
