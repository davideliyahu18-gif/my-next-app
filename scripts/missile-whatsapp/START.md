# התחלה מהירה — בלי Green API

הקבוצה: **🛡️ מרכז התרעות אזורי**

## במחשב שלכם

```bash
cd scripts/missile-whatsapp
npm install
npm start
```

1. יופיע QR במסוף  
2. בוואטסאפ: **הגדרות → מכשירים מקושרים → קישור מכשיר**  
3. סרקו  
4. הבוט מוצא את הקבוצה ושולח **הודעת בדיקה + סיכת מיקום**

בדיקה נוספת (כשהבוט רץ):

```bash
npm run test-send
```

זה הכל. אין צורך ב-Green API.
